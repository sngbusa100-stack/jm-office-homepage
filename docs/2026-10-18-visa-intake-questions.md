## 1. 질문 선정 기준

첫 접수 질문은 그 답이 아래 넷 중 하나 이상을 **실제로 바꿀 때만** 넣습니다.

1. **긴급도**: 언제까지 움직여야 하는가
2. **경로**: 사증·사증발급인정서 / 변경 / 연장 / 보완 대응 / 불허 대응 중 어느 것인가
3. **큰 걸림돌**: 진행을 막을 수 있는 사유가 있는가
4. **응대 방식**: 누구와, 어떤 언어로 응대하는가

세부 요건(소득·학력·경력·계약·가족 구성·세금)은 비자 진단이나 회신 단계에서 묻습니다.

## 7. 검토자 의견이 갈린 점과 결정

질문 5(위반 이력)에 대해 세 검토자의 의견이 갈렸습니다.
- 실무: 선택 항목으로 두고 과거와 현재를 나누자.
- 법: 민감정보 위험이 있으니 폼에서 빼고 상담 단계로 옮기자.
- 고객: 선택 항목으로 두고 진단 라벨과 맞추자.

절충안을 택했습니다. 질문 범위를 **체류기간 초과·출국명령·과태료·범칙금 같은 출입국 행정 처분**으로 좁히고, 형사재판·벌금형은 적지 말라고 안내합니다. 선택 항목으로 두고 '상담 때 말씀하겠음'을 선택지에 넣었습니다. '현재 해결되지 않은 문제'는 긴급도를 바꾸므로 남겼습니다. 민감정보 해석이 확인되면 다시 판단합니다.

| 회사 | 직원은 지금 어디에 있나요? 한국에 있다면 체류기간은 어떤가요? |
| 가족 초청 | 초청하려는 가족은 지금 어디에 있나요? 한국에 있다면 체류기간은 어떤가요? |

- 선택지(비자 진단 라벨과 같음): 현재 해외에 있음 / 한국에 있음 · 체류기간이 유효함 / 한국에 있음 · 만료가 임박함(약 2개월 이내, 사무소 안내 기준) / 한국에 있음 · 이미 만료됨 / 잘 모르겠음
- 만료일(선택): "외국인등록증, 최근 받은 허가 문자, 하이코리아(hikorea.go.kr)에서 확인할 수 있어요. 모르시면 비워 두세요."
  - 도움말에 '등록증 뒷면은 최신이 아닐 수 있음'은 넣지 않습니다. 공식 원문으로 확인하지 못했기 때문입니다.

### 질문 2 — 지금 체류자격 (해외가 아닐 때)

| 대상 | 문구 |
|---|---|
| 본인 | 지금 가지고 있는 체류자격(비자 종류)은 무엇인가요? |
| 회사 | 직원의 지금 체류자격(비자 종류)은 무엇인가요? |
| 가족 초청 | 가족의 지금 체류자격(비자 종류)은 무엇인가요? |

- 도움말: "외국인등록증 앞면 '체류자격' 칸의 영문·숫자예요(예: E-7). 등록증이 없으면 여권에 찍힌 입국 도장이나 받은 비자를 보세요."
- 선택지
  - 비자 없이 입국(무비자) 또는 짧은 방문(C-3·C-4) / 유학·어학연수(D-2·D-4) / 구직(D-10) / 취업(E-7·E-9·H-2 등) / 결혼·거주·동포·영주(F-2·F-4·F-5·F-6) / 그 밖의 자격(코드만 입력, 예: D-8) / 잘 모르겠음 / 답하지 않음
  - 비자 없이 입국했다면 '무비자'라고만 적고 B-1·B-2 코드는 괄호 안 도움말로 둡니다. 고객은 이 코드를 거의 모르기 때문입니다.

### 질문 3 — 무엇을 하려고 하시나요?

| 대상 | 문구 |
|---|---|
| 본인 | 무엇을 하려고 하시나요? |
| 회사 | 직원에게 어떤 절차가 필요하신가요? |
| 가족 초청 | 가족에게 어떤 절차가 필요하신가요? |

- 선택지: 처음 한국에 오기(비자 받기·초청) / 지금 체류기간 늘리기(연장) / 다른 체류자격으로 바꾸기(변경) / 영주(F-5) 또는 귀화 / 가족을 초청하거나 함께 지내기 / 잘 모르겠음
- 원하는 체류자격(선택): 질문 2와 같은 목록
- 해외이거나 '처음 한국에 오기'일 때: "언제까지 한국에 와야 하나요?" — 월 선택 / 아직 정해지지 않음
  - 회사: "언제부터 근무해야 하나요?"
  - 가족 초청: "언제부터 함께 지내려고 하시나요?"

### 질문 4 — 이미 신청했거나 출입국 기관에서 받은 연락·문서가 있나요?

- 문구는 세 대상 모두 같습니다. 회사·가족일 때는 "(비자를 받을 분이)"를 앞에 붙입니다.
- 선택지: 아직 신청 전 / 신청하고 결과를 기다리는 중 / 서류를 더 내라는 요청(보완)이나 출석 요청을 받음 / 허가되지 않았다(불허)는 결과를 받음 / 출국하라는 안내(출국기한·출국명령)를 받음 / 행정심판이나 소송을 이미 하고 있음 / 잘 모르겠음
- 보완·불허·출국 안내일 때
  - "받은 날짜" — 날짜 / 잘 모르겠음
  - "문서에 적힌 마감일" — 날짜 / 마감일 없음 / 잘 모르겠음
  - 도움말: "받은 문자나 문서에 적힌 날짜를 적어 주세요."

### 질문 5 — (선택) 출입국 관련 기록

| 대상 | 문구 |
|---|---|
| 본인 | 체류기간을 넘긴 적이 있거나, 출입국 기관에서 출국명령·과태료·범칙금 통지를 받은 적이 있나요? |
| 회사·가족 | (비자를 받을 분이) 체류기간을 넘긴 적이 있거나, 출입국 기관에서 출국명령·과태료·범칙금 통지를 받은 적이 있나요? |

- 선택지: 없음 / 예전에 있었고 끝남 / 지금 해결되지 않은 문제가 있음 / 잘 모르겠음 / 상담 때 말씀하겠음
  - 값은 진단의 none / past / current / unsure와 대응합니다. '상담 때 말씀하겠음'은 값을 비워 둡니다.
- 안내: "자세한 내용이나 형사재판·벌금형 같은 내용은 여기에 적지 마세요. 답하지 않아도 상담을 받으실 수 있어요."

### 질문 6 — 연락드릴 때 쓸 언어

| 대상 | 문구 |
|---|---|
| 본인 | 어떤 언어로 연락받기 편하신가요? |
| 회사·가족 | 신청하시는 분께 어떤 언어로 연락드릴까요? (보통 한국어) |

- 선택지: 한국어(기본 선택) / English / 中文 / Tiếng Việt / 日本語 / 그 밖의 언어(언어 이름)
- 국적(해외이거나 처음 오기일 때, 선택)
  - 본인: "국적은 어디인가요?"
  - 회사·가족: "비자를 받을 분의 국적은 어디인가요?"
  - 도움말: "나라마다 비자 서류가 달라서 여쭤요. 답하지 않아도 됩니다."
