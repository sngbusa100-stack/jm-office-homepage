## 1. 요약

지금 사이트는 문구, 개인정보, 접수 연동, 검사 스크립트가 잘 갖춰져 있습니다. 남은 약점은 네 가지입니다.

1. **운영 설정이 비어 있습니다.** 보안 헤더가 HSTS 하나뿐이고, 없는 파일을 요청해도 200과 빈 화면용 HTML이 나갑니다. 배포 직후 열려 있던 탭이 하얗게 멈출 수 있습니다. (카드 A1, A2)
2. **검색에서 찾기 어려운 제목입니다.** 업무 페이지 제목이 "인허가 대리 | 정명 행정사사무소"처럼 업무명뿐입니다. 사람들이 검색하는 말(기한, 준비서류, 반려)이 제목에 없습니다. (A3, A4, A5)
3. **명함 1번 분야인 인허가 페이지가 가장 얇습니다.** 본문 978자, 서류 예시 4줄, 질문 2개입니다. 토지개발과 공공조달은 상세 페이지가 아예 없습니다. (C1~C3)
4. **모바일 세부가 덜 다듬어졌습니다.** 누르는 영역이 작은 곳이 많고, 대표 사진은 첫 화면에서 보이지 않습니다. (A6, A7, B1)

권장 순서는 5절에 있습니다.

## 3. 구현하는 모델이 지킬 공통 규칙

카드를 맡기실 때 이 절을 함께 주시면 됩니다.

1. **한 번에 카드 한 장만** 합니다. 카드에 적힌 파일 밖은 건드리지 않습니다.
2. 시작 전에 `git status`를 봅니다. 미커밋 변경이 있으면 멈추고 주인님께 알립니다.
3. 끝나면 `npm run check`(타입 검사, 테스트, 빌드, dist 검사)를 돌리고 결과 숫자를 그대로 보고합니다. 실패하면 실패했다고 적습니다.
4. 화면 확인은 `npm run build` 뒤 dist 미리보기로 합니다. 개발 서버(:5173)는 `/api` 프록시 문제로 화면이 비어 있습니다.
5. **커밋, 푸시, 배포는 하지 않습니다.** master에 푸시하면 운영에 바로 나갑니다. 주인님 승인 뒤에만 합니다.
6. **고객이 읽는 문구를 새로 짓지 않습니다.** 이 문서에 적힌 문구만 쓰고, 없으면 `(문구 필요)`로 남깁니다. 법정 기한, 조문 번호, 요건은 기억으로 쓰지 않습니다.
7. 금지: 결과 보장, 실적 숫자, "대리"로 읽히는 행정심판 표현, "원스톱", 외부 CDN 글꼴, 서비스 워커, 사전 렌더링되는 페이지에 `React.lazy`, 빌드 시각으로 `lastmod` 채우기. 전체 목록은 10-17 보고서 7절입니다.
8. 분야 이름 문자열(`consultTopic`, `TOPICS`)은 바꾸지 않습니다. 로컬 연동이 조용히 깨집니다.
9. 끝나면 `checklist.md`와 `memory.md`에 한 일과 확인 결과를 적습니다.

**모델 구분.** 아래 카드의 `난이도` 칸에서 `기계적`은 싼 모델에 그대로 맡겨도 되는 일입니다. `검토 필요`는 싼 모델이 구현하되 주인님이나 상위 모델이 결과를 봐야 하는 일입니다. `문구·법령`은 내용을 먼저 확정한 뒤에 구현만 맡기는 일입니다.

#### A1. 보안 헤더와 캐시 · 난이도: 검토 필요 · 작업량 M

- **왜:** 관리자 화면이 접수 개인정보를 다루는데 브라우저 보호 헤더가 없습니다. 해시가 붙은 파일도 방문할 때마다 서버에 다시 묻습니다.
- **무엇을:**
  - `vercel.json` 공통 헤더: `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY`, `Permissions-Policy: camera=(), microphone=(), geolocation=()`.
  - CSP는 **`Content-Security-Policy-Report-Only`로만** 넣습니다. 값: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self' https://jungmyungoffice.com; form-action 'self'; frame-ancestors 'none'; base-uri 'self'; object-src 'none'`.
  - `/assets/(.*)`는 `public, max-age=31536000, immutable`. `/images/(.*)`는 `public, max-age=86400, stale-while-revalidate=604800`.
  - `api/_cors.mjs`의 `applyCors`에 `Cache-Control: no-store`, `Vary: Origin`, `X-Content-Type-Options: nosniff`. 허용 출처에서 `https://sngbusa100-stack.github.io`를 뺍니다. `http://localhost:5173`은 그대로 둡니다.
- **파일:** `vercel.json`, `api/_cors.mjs`, `src/test/vercelConfig.test.ts`, `api/_admin.test.mjs`, `api/_consult.test.mjs`
- **완료 기준:** 테스트에 헤더 검사가 추가되고 통과합니다. 배포 뒤 `curl -sI`로 헤더가 보입니다. 브라우저 콘솔에서 19개 경로와 /admin, 진단→상담 흐름의 CSP 위반이 0건입니다.
- **주의:** CSP 강제 전환은 이 카드에서 하지 않습니다. 위반 0건을 확인한 뒤 주인님 승인으로 따로 합니다. HSTS에 `includeSubDomains`와 `preload`를 붙이지 않습니다.
