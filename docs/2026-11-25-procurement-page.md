# 공공조달 업무 상세 페이지 (2026-11-25)

주인님 지정 범위(2026-11-25): "직접생산확인, 여성기업확인, 입찰참가자격 확인? 너의 추천대로 해". 개선 목록 C3(`docs/2026-11-12-improvement-backlog.md`)를 이 범위로 만든다. 입찰참가자격은 '확인'이 아니라 나라장터 '등록'이 법령상 이름이라(국가계약법 시행규칙 제15조) 그렇게 적었다.

## 정한 것 (내 추천안으로 진행, 주인님 확인 목록에 올림)

| 항목 | 정한 값 | 이유 |
|---|---|---|
| 주소 | `/services/procurement` | 업무 분야 '공공조달 · 기업인증'의 첫 상세 페이지 |
| 업무 분야 | `serviceAreas.ts`의 `procurement`에 연결 | 지금까지 상세 페이지가 없어 "준비하고 있습니다"만 보였다 |
| 상담 분야 | 기존 `permit`(인허가) | 토지개발 페이지와 같은 이유(접수 계약·로컬 연동을 바꾸지 않음) |
| 유입 통계 코드 | 새 `procurement` | 페이지 성과를 따로 본다 |
| 법정 기한 칸 | 넣지 않음 | 신청 업무라 하단 상담 버튼을 기한 우선으로 두지 않는다 |
| 정책자금 | 다루지 않음 | '대행·알선'으로 읽힐 위험(개선 목록 C3 주의) |
