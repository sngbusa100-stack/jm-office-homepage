# 홈페이지 상담 저장 장애 대응

텔레그램에 ‘홈페이지 접수 저장 확인 필요’가 표시되면 확인번호와 발생 시각을 확인한다. 고객 화면에는 같은 신청 화면에서 1분 뒤 다시 신청할 수 있다는 안내가 표시된다.

1. 저장소 연결 상태와 관리자 목록을 확인한다. 기존 접수 본문만 저장된 경우 같은 신청 재시도로 목록 인덱스를 복구할 수 있다.
2. 정상화 뒤 같은 확인번호가 관리자 목록과 PC 대기함에 한 번씩 보이는지 대조한다. 저장소 장애가 접수번호 선점보다 먼저 발생하면 장애 확인번호와 재시도 후 접수번호는 다를 수 있다.
3. 알림 전송만 실패했을 때는 접수가 저장되어 고객에게 접수번호가 표시된다. 미처리 문의는 관리자 목록에서 확인한다.
