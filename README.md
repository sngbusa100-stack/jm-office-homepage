정명(正明) 행정사사무소 홈페이지는 Vercel 한 곳으로 통일했습니다.
운영 주소: https://jm-office-homepage.vercel.app

이 브랜치에는 옛 GitHub Pages 주소로 들어온 방문자를 새 주소로 보내는
리다이렉트 페이지만 남아 있습니다. 경로는 그대로 이어 붙여 전달합니다.
(예: /jm-office-homepage/services/license -> https://jm-office-homepage.vercel.app/services/license)

저장소 Settings > Pages에서 Pages 기능을 완전히 끄면 이 브랜치도 지울 수 있습니다.
